# Clandescent Moon

Egy React 18 projekt amit azért készítettem, hogy megtanítsam magamnak a ReactPlayer használatát, az i18next nyelvválasztó keretrendszert, a Papaparse CSV fájlelemzőt illetve hogy legyen egy felhasználó független videó lejátszó listám amin keresztül zenét hallgathatok munka közben. Részletesebb leírásért keresd fel a [https://www.fabokarpad.hu/portfolio-x/clandescent-moon/](https://www.fabokarpad.hu/portfolio-x/clandescent-moon/) oldalt. Ha van bármilyen kérdésed az itt látottakkal kapcsolatban akkor küldj egy emailt a [farpadmail@gmail.com](mailto:farpadmail@gmail.com) címre, esküszöm néha olvasom őket.
